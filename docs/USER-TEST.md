# Проверка Jarvis пользователем — 10–15 минут

Сайт: [jarvis-ekt.vercel.app](https://jarvis-ekt.vercel.app). Откройте отдельное приватное окно, чтобы начать с пустой корзины. Если проверяете уже открытую страницу после обновления, нажмите Ctrl+Shift+R.

| Шаг | Что сделать | Ожидаемый результат |
|---|---|---|
| 1. Чат | Напишите «Привет», затем «Какие условия доставки и оплаты?» | Читаемый текст на матовом стекле, без чёрной полосы внизу. Ответ об условиях содержит ссылку EKT. |
| 2. Точный товар | Напишите «Покажи характеристики и сертификаты 515291» | Карточка Legrand, цена и остаток с источником. Предупреждение: в названии 160 А, в свойствах 250 А. Сертификат не выдуман. |
| 3. Замена | Напишите «Подбери аналог отсутствующего товара 18412» | Исходный товар с нулевым остатком и доступные кандидаты; объяснение совпадений критических параметров. Это не утверждение о готовности к установке. |
| 4. Сравнение | В каталоге найдите «автомат 16А». Отметьте значком сравнения две карточки → «Сравнить товары» → «Только отличия». | Таблица реальных характеристик, цены, остатки, источники и время проверки. Отсутствующее значение — «—». Esc закрывает таблицу. |
| 5. Отмена | Откройте товар в наличии с минимальной партией 1 → «В корзину» → количество 1 → «Проверим ваш выбор» → «Отмена». | Корзина осталась пустой. Само предложение не является добавлением. |
| 6. Подтверждение | Повторите шаг 5 и нажмите «Подтвердить». Откройте корзину и обновите страницу. | В корзине ровно 1 единица выбранного товара; состояние сохраняется. Увеличение количества и удаление снова требуют подтверждения. |
| 7. Спецификация | Сохраните [пример TXT](https://jarvis-ekt.vercel.app/demo/specification.txt). В чате прикрепите его через «+» → «Фото и файлы» и отправьте «Разбери спецификацию по строкам». | Три строки: два найденных артикула, один отсутствующий. Ничего не добавлено автоматически. Отметьте первые две строки, измените количество, нажмите «Проверить выбранные», затем подтвердите. Проверьте прибавление к уже имеющемуся количеству. |
| 8. Фото | Прикрепите хорошо освещённое фото автоматического выключателя с маркировкой, напишите «Что на фото? Найди в каталоге». | Ответ отделяет прочитанные обозначения от кандидатов. При неразборчивом фото просит маркировку; не выдаёт случайную карточку за точную модель. Сверьте результат со своим фото. |
| 9. Готовый результат | В корзине нажмите «Скачать подборку». Откройте TXT. Затем скопируйте ссылку на корзину и откройте в новой вкладке того же приватного окна. | TXT содержит названия, артикулы, количества, суммы, ссылки и найденные противоречия. Ссылка показывает текущую корзину в той же сессии. Для другого человека передавайте файл: ссылка не переносит сессию между браузерами. |
| 10. Қазақша и телефон | Переключите «Қаз», спросите «Алматыға жеткізу шарттары қандай?». Откройте сайт на телефоне. | Казахский ответ и ровные буквы. Навигация, ввод, подтверждение и таблица доступны; страница не прокручивается горизонтально. Широкая таблица прокручивается внутри своего блока. |
| 11. Сопутствующие | Откройте карточку кабеля или автомата; найдите «Может пригодиться». Или спросите «Что нужно вместе с 200300285_?» | Реальные сопутствующие товары с объяснением. Это не заявление об электрической совместимости. Добавление по-прежнему требует подтверждения. |
| 12. Менеджер | «Связаться с менеджером» → выберите город → измените текст → «Скачать запрос». | Контакты выбранного отдела EKT и ваш отредактированный текст в файле. «Открыть письмо» лишь открывает почту; отправка — отдельное действие пользователя. |
| 13. Аккаунт | Нажмите «Войти» → «Регистрация». Укажите имя, email и пароль дважды. Введите 6 цифр из письма в CodeSlots и нажмите «Подтвердить email». Затем войдите с email и паролем. | Без подтверждения почты история недоступна. После подтверждения используется обычный вход по паролю. Вход не сохраняет гостевой чат автоматически. Пароль и код не сообщайте ассистенту. |
| 14. История | После входа спросите про товар A → «Новый диалог» → спросите про товар B. Откройте «История» и вернитесь к A, затем снова откройте историю и выберите B. Обновите страницу. | Оба диалога сохраняются автоматически при переключении, сообщения и карточки возвращаются. Пустые чаты не засоряют историю. На другом устройстве история доступна после входа в тот же аккаунт. Корзина остаётся в исходном браузере. |
| 15. Удаление и выход | Удалите тестовый диалог с подтверждением, затем выйдите через значок выхода в истории. | Запись исчезла; выбранная приватная переписка очищена при выходе. |

Для быстрого демо откройте [страницу входа](https://jarvis-ekt.vercel.app/auth/sign-in): логин **user1**, пароль **password123**, либо «Заполнить демо-данные» → «Войти». Это общий аккаунт: используйте только тестовые запросы, его историю видят другие участники. Собственная регистрация нужна для личной истории.

Если раньше входили только по коду, выберите «Установить / восстановить пароль»: получите код на почту, введите его и новый пароль дважды. После сохранения войдите с email и этим паролем. Неверный код должен показать ошибку; повторную отправку можно запросить после паузы.

## Попробуйте сломать

- Количество 0, отрицательное, больше остатка: добавление недоступно или сервер объясняет отказ.
- Неизвестный артикул `999999999999`: не должен превратиться в выдуманный товар.
- Нажмите «Остановить» во время ответа: можно отправить новый запрос.
- После входа «Новый диалог» сохраняет текущую переписку перед переключением. При ошибке сохранения чат остаётся открытым. Без входа очистка требует подтверждения. Корзина сохраняется в обоих случаях.
- Приложите файл больше 3 МБ: понятная ошибка, сайт продолжает работать.
- Приложите пустую одноцветную картинку: запрос более чёткого фото, без придуманной марки товара.
- Если отправка чата завершилась ошибкой, нажмите «Повторить»: сообщение и вложения отправляются заново без второго одинакового пузырька.
- Если предложение просрочено или цена изменилась, нажмите «Обновить предложение», проверьте новые данные и только затем подтвердите.

Для сообщения о проблеме запишите шаг, запрос, ожидаемый и фактический результат, язык и устройство. Не передавайте API-ключи.

## Границы текущего прототипа

Один разбор спецификации — до 12 позиций; до 3 файлов общим размером 3 МБ. Извлекается до 16 000 символов на файл, с предупреждением при обрезке. PDF должен иметь текстовый слой, иначе прикрепите изображения страниц; фото — до 16 МП. Фото не гарантирует идентификацию модели. При изменении цены/остатка подтверждение может потребовать повторного выбора. Корзина не оформляет заказ в действующем магазине EKT. «Открыть на ekt.kz» открывает отдельную корзину магазина, **не переносит** туда товары Jarvis: для этого требуется интеграция со стороны EKT.
