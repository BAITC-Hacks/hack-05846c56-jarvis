# Объединение исходных заготовок

Все восемь исходных файлов пользователя сохранены без изменений в `references/ui/`. SHA-256 копий совпадает с исходниками. Общая структура приложения сохранена: ассистент, каталог, карточка товара, сравнение и корзина с подтверждением.

| Исходник | Компонент приложения | Что сохранено |
|---|---|---|
| get started button.html | SpecularButton + prototype-specular.js | Слои кнопки, WebGL-шейдер и реакция блика на указатель |
| Prompt Bar.html | PromptBar | Поле, меню, вложения, ползунок из пяти позиций, частицы, переход отправить/стоп |
| навигация.html | GooeyNav | Структура навигации, активная плашка, частицы и переходы |
| логотип.html | original/DepthLogo | 34 слоя, глубина, наклон, движение и исходные цвета |
| фон.html | original/OriginalDotField | Сетка точек, градиент и физика реакции на курсор |
| Scroll Reveal.html | original/ScrollReveal | Разбиение на слова, появление, поворот и размытие при прокрутке |
| бегущая строка.html | original/ScrollVelocity | Вложенная структура, повторы текста, скорость и направление от прокрутки |
| плавный скролл.js | original/SmoothScroll | Lenis duration 1.35, исходная кривая и синхронизация GSAP |

Отдельные HTML-демо перенесены в React: глобальные стили страницы ограничены компонентами, обработчики и анимации очищаются при размонтировании. Учитывается системная настройка уменьшения движения. Прокрутка диалогов и ввода не перехватывается Lenis.

Демонстрационные пункты строки ввода подключены к задачам покупателя: подбор, аналоги, сравнение, условия покупки. Ползунок задаёт максимальную цену за единицу; по умолчанию ограничения нет. Выбранный предел передаётся в запрос и проверяется сервером. Голосовой ввод доступен только в браузерах с SpeechRecognition.

Тексты интерфейса локализованы на RU/KK. Корзина, реальные цены и остатки, источники, вложения и явное подтверждение работают независимо от декоративных эффектов.

По последующим правкам участника убраны боковая панель и отдельная верхняя строка. RU/KK расположены рядом с тремя пунктами навигации. Навбар закреплён при прокрутке, фон прозрачный с размытием. Для прозрачного фона чёрная маска Gooey заменена фильтром по альфа-каналу; частицы и переходы сохранены. Фиолетовая рамка ввода убрана, фокус обозначается мягкой нейтральной границей общего поля.

Четыре карточки действий используют BorderGlow из предоставленного участником кода React Bits (`references/ui/BorderGlow.txt`). Сохранены градиентные маски и расчёт направления подсветки; добавлены типы TypeScript, отмена анимаций, поддержка reduced motion и клавиатурного фокуса. Пункты меню получили одну ровную активную плашку: дополнительная размытая белая форма удалена, частицы перехода сохранены.

Последующие правки интерфейса: подпись EKT INTELLIGENCE удалена; меню и CTA используют единые шрифт, высоту и радиус. Три пункта меню центрированы независимо от ширины элементов по краям. Исходный точечный фон стал общим фиксированным слоем для ассистента, каталога и корзины; координаты указателя рассчитываются относительно окна. Шапка имеет полупрозрачную поверхность и backdrop blur 48px.

DriftWall и WarpText перенесены из кода участника React Bits: исходники сохранены в references/ui. DriftWall на главной показывает только фотографии 20 товаров EKT, открывает существующее окно товара; полная страница каталога сохранена. Движение приостанавливается вне экрана/в скрытой вкладке и при reduced motion. WarpText (ogl) выводит by EKT справа под главным Jarvis под углом 45°, с текстовым резервом без WebGL.

Бегущая строка: нестабильная интеграция пружины заменена экспоненциальным сглаживанием, число повторов зависит от ширины окна, убран фильтр тени, добавлен верхний отступ 32px.

Neue Machina не содержит 16 из 18 специфических казахских символов. Казахский интерфейс и тексты с казахскими буквами используют целиком Noto Sans ExtraBold 800 (проверено покрытие ӘәҒғҚқҢңӨөҰұҮүҺһІі), локальный файл и лицензия OFL находятся в public/fonts. Размеры шрифта не изменены; Neue Machina сохранён для русского интерфейса и логотипа.

CodeSlots для шестизначного кода подтверждения почты адаптирован из присланного участником React Bits [Code Slots](https://reactbits.dev/micro/code-slots). Сохранены каскадное заполнение, пружины, каретка и анимация успешной проверки; добавлены типы TypeScript, RU/KK подписи, мобильное автозаполнение, очистка анимаций и защита от повторного `onComplete`. Используется Motion; галочка заменена на уже установленный Lucide. Изолированный браузерный тест проверяет клавиатуру, вставку, controlled value и reduced motion без отправки писем.
