# Объединение исходных заготовок

Все восемь исходных файлов пользователя сохранены без изменений в `references/ui/`. SHA-256 копий совпадает с исходниками. Общая структура приложения сохранена: ассистент, каталог, карточка товара, сравнение и корзина с подтверждением.

| Исходник | Компонент приложения | Что сохранено |
|---|---|---|
| get started button.html | SpecularButton + prototype-specular.js | Слои кнопки, WebGL-шейдер и реакция блика на указатель |
| Prompt Bar.html | PromptBar | Поле, меню, вложения, ползунок из пяти позиций, частицы, переход отправить/стоп |
| навигация.html | GooeyNav | Структура навигации, активная плашка, частицы и переходы |
| логотип.html | original/DepthLogo | 34 слоя, глубина, наклон, движение и исходные цвета |
| фон.html | original/OriginalDotField | Сетка точек, градиент и физика реакции на курсор |
| Scroll Reveal.html | original/ScrollReveal | Разбиение на слова, появление, поворот и размытие при прокрутке |
| бегущая строка.html | original/ScrollVelocity | Вложенная структура, повторы текста, скорость и направление от прокрутки |
| плавный скролл.js | original/SmoothScroll | Lenis duration 1.35, исходная кривая и синхронизация GSAP |

Отдельные HTML-демо перенесены в React: глобальные стили страницы ограничены компонентами, обработчики и анимации очищаются при размонтировании. Учитывается системная настройка уменьшения движения. Прокрутка диалогов и ввода не перехватывается Lenis.

Демонстрационные пункты строки ввода подключены к задачам покупателя: подбор, аналоги, сравнение, условия покупки. Ползунок задаёт максимальную цену за единицу; по умолчанию ограничения нет. Выбранный предел передаётся в запрос и проверяется сервером. Голосовой ввод доступен только в браузерах с SpeechRecognition.

Тексты интерфейса локализованы на RU/KK. Корзина, реальные цены и остатки, источники, вложения и явное подтверждение работают независимо от декоративных эффектов.
