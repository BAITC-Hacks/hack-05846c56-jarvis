## Сделано за первый час

- Изучены кейс, API партнёра, критерии оценки и предоставленные визуальные материалы. Реализована архитектура Next.js / React / TypeScript с серверными адаптерами EKT и OpenAI.
- Проверен доступ к реальному API EKT; подготовлен поисковый индекс **15 035 товаров**, подробная выборка **608 карточек** с источником и временем получения.
- Реализованы поиск по артикулу и параметрам, карточка с ценой, остатками, складами, характеристиками и ссылками источника. Недоступные ссылки сертификатов не выдумываются.
- Подключён OpenAI; реализованы консультации на русском и казахском, память диалога, ответы об оплате/доставке, ограничение бюджета покупателя.
- Реализован объяснимый подбор аналогов: несовпадающие критические характеристики и противоречия источника исключают подтверждение совместимости.
- Создана корзина прототипа: предложение не меняет состав; добавление, изменение и удаление требуют отдельного подтверждения. Сервер повторно проверяет остаток, цену и кратность. Ссылка `/cart` открывает актуальное состояние текущего браузера.
- Поддержана загрузка PDF, DOCX, XLSX, CSV, TXT и изображений. Файлы обрабатываются в памяти и не сохраняются приложением на сервере.
- Собран локальный интерфейс RU/KK с каталогом, чатом, сравнением и корзиной; объединены восемь исходных UI-заготовок. Оригиналы сохранены в `references/ui/`.
- Подготовлены README с установкой/запуском, схема архитектуры, сценарий проверки, матрица критериев и журнал тестирования.

## Ограничения текущего этапа

- API корзины EKT не предоставлен. Корзина Jarvis — явно обозначенный прототип, без заказа, резервирования и оплаты.
- При недоступности API можно просматривать датированную выборку; изменение корзины, требующее актуального остатка, блокируется.
- PDF без текстового слоя требует изображения страницы. Поддерживаются современные DOCX/XLSX, а не старые DOC/XLS.
- Публичное развёртывание пока отложено по решению участника; локальная версия запущена. Секреты находятся только в серверном окружении и не включаются в Git.
