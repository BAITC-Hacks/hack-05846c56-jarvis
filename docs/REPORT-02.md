## Соответствие и ограничения

Пять основных требований кейса реализованы на уровне прототипа: данные товара, объяснимые аналоги, условия покупки, корзина только после подтверждения, прямая ссылка на её текущее состояние. Таблица доказательств — [RELEASE-CHECK.md](RELEASE-CHECK.md).

Корзина принадлежит прототипу, а не действующему магазину EKT: API оформления заказа и сессии магазина не предоставлены. При недоступности API каталог явно показывает датированный снимок; изменение корзины требует свежей проверки. Сканы PDF без текста загружаются как изображения. Эти ограничения не скрываются при демонстрации.
