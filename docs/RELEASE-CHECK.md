# Проверка перед демонстрацией

Дата: 23 сентября 2026. Публичная демонстрация: https://jarvis-ekt.vercel.app.

## Фактически выполнено

- 25 модульных тестов: все прошли.
- 12 HTTP-сценариев локально и те же 12 на Vercel: все прошли, тестовая корзина очищена.
- Браузер: выбор товара фотографией, предложение и подтверждение, корзина после перезагрузки, удаление, RU/KK и поиск артикула прошли.
- XLSX и DOCX распознаются локально и на Vercel. Локально также проверены PDF, TXT, отказ для поврежденного PDF и файла больше 3 МБ.
- Локальная production-сборка и первый облачный build успешны.
- Первый публичный PDF-тест выявил неполный серверный пакет: добавлен pdf-parse/worker и явное включение native canvas/worker.
- Мобильный тест нашёл 6px горизонтального переполнения от canvas кнопки: добавлен overflow-x:clip шапки.

## Что важно для оценки

По положению: ценность 25, качество 20, инновационность 15, масштабирование 20, презентация/демо/ответы 20. Это веса критериев, а не набранные командой баллы. Сценарий демонстрации и аргументы — в JUDGING.md. README содержит самостоятельный запуск, архитектуру, зависимости и переменные окружения (п. 5.4.15).

Ограничения: отдельный прототип, не установлен на действующий ekt.kz; настоящие API корзины и оформления заказа партнёром не предоставлены. Ссылка /cart привязана к текущему браузеру. Сканы PDF без текстового слоя нужно загрузить изображением. Ответы зависят от API: в одном локальном тесте было 24,8 с; на Vercel тот же сценарий занял 6,2 с. Уровень точности, экономия и гарантированный итоговый балл не заявляются.
