## Обязательные требования кейса

| Требование | Реализация | Доказательство на демонстрации |
|---|---|---|
| Товар, наличие, характеристики, сертификаты | Адаптер EKT, подробная карточка, склады, source/fetchedAt, ссылки источника | Запрос конкретного артикула; сопоставление с ответом API |
| Аналог отсутствующего товара с обоснованием | Детерминированное сравнение критических параметров, отдельная проверка конфликтов | Исходный товар с нулевым остатком; доступный кандидат; объяснение совпадений |
| Условия покупки | Проверенная официальная страница EKT | Вопрос про оплату и доставку; ссылка на страницу условий |
| Корзина только после явного подтверждения | Подписанное предложение, отдельный confirm, свежие остатки/цена/кратность | Отмена не меняет корзину; подтверждение добавляет; превышение остатка отклоняется |
| Прямая ссылка на актуальную корзину | /cart, подписанная сессия браузера | Обновление страницы сохраняет корзину |

Дополнительно: RU/KK, загрузка спецификаций/фото, сравнение, мобильный интерфейс. API настоящей корзины EKT не предоставлен: граница прототипа описана честно.

## Сценарий демонстрации (3–4 минуты)

Это рекомендуемый тайминг репетиции, не регламент из положения. Формат защиты объявляет организатор; требования обязательного файла слайдов или видео в предоставленном документе нет.

1. **Проблема, 20 секунд.** Покупателю приходится звонить для уточнения характеристик, наличия и замен. Показываем консультацию в одном окне.
2. **Запрос, 40 секунд.** Артикул → настоящая карточка, цена, остатки по складам, источник. Переключение на қазақша с продолжением контекста.
3. **Подбор, 45 секунд.** Отсутствующая позиция → кандидат с совпадающими критическими параметрами. Показать, что отличающийся ток не скрывается.
4. **Корзина, 45 секунд.** Указать количество; показать пустую корзину до подтверждения, затем подтвердить и открыть /cart. Попытка заказать сверх остатка получает понятный отказ.
5. **Спецификация, 30 секунд.** Загрузить небольшой XLSX/DOCX/PDF или фото и получить конкретный поиск.
6. **Качество и внедрение, 30 секунд.** Проверки, README, реальные ограничения и способ подключения к корзине EKT.

## Ответы на вероятные вопросы

- **Почему можно доверять цене?** Цена и остаток берутся из каталога; перед добавлением сервер повторно проверяет данные. Датированная копия явно обозначена и не позволяет подтвердить остаток.
- **Может ли AI сам оформить заказ?** Нет: модель не имеет инструмента изменения корзины; сервер принимает только отдельное подтверждение. Оплата и оформление заказа в прототип не входят.
- **Что при сбое API?** Доступна датированная выборка для просмотра; операция, требующая актуальных остатков, блокируется с сообщением.
- **Какой экономический эффект?** Ожидается сокращение повторяющихся консультаций и времени подбора. Процент роста продаж не заявляем без пилотных измерений.
- **Как внедрять?** Согласовать API корзины/сессии и источники сертификатов, подключить адаптер, провести пилот с менеджерами и измерить долю решённых обращений и корректность подбора.

## Честные измерения

Результаты тестов и фактическая задержка записываются в QA/PROGRESS после запуска. До измерения не заявляем процент точности, экономию или SLA. Синтетические автоматические тесты не выдаём за реальные товарные остатки.
