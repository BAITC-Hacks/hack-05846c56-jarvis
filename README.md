# Jarvis · AI-консультант EKT

Кейс HackAlem AI: консультация по реальному каталогу ekt.kz, объяснимый подбор кандидатов на замену, чтение спецификаций и корзина с явным подтверждением. Интерфейс и ответы: **русский / қазақша**.

**[Открыть демо](https://jarvis-ekt.vercel.app)** · [Проверить как пользователь](docs/USER-TEST.md) · [Отчёт второго часа](docs/REPORT-02.md) · [Последние улучшения и критерии](docs/PRODUCT-UPGRADE.md)

## Запуск для эксперта

Node.js 22.13+ (рекомендуется 24 LTS), npm. Клонируйте репозиторий организатора, установите зависимости и скопируйте `.env.example` в `.env.local`:

```bash
git clone https://github.com/BAITC-Hacks/hack-05846c56-jarvis.git
cd hack-05846c56-jarvis
npm ci
# Скопируйте .env.example в .env.local средствами своей ОС.
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Последняя команда генерирует значение `CART_SECRET`. Заполните `.env.local`:

| Переменная | Назначение |
|---|---|
| CART_SECRET | Случайная строка минимум 32 символа, подпись корзины |
| EKT_API_URL | https://ekt.kz/api |
| EKT_API_USERNAME, EKT_API_PASSWORD | Basic Auth из пакета данных партнёра |
| OPENAI_API_KEY | Серверный ключ OpenAI |
| OPENAI_MODEL | По умолчанию gpt-4.1-mini |

```bash
npm run dev
# http://localhost:3000
```

Проверки и production-запуск:

```bash
npm test
npm run typecheck
npm run build
npm start
```

Без ключа OpenAI доступен явно обозначенный режим ответов по каталогу. Без API EKT работает датированная выборка, но добавление в корзину блокируется: неподтверждённый остаток не выдаётся за актуальный. Посетителю настроенной демонстрации не нужен личный аккаунт участника.

## Возможности

- Поиск по названию, ID, артикулу и параметрам; цена в тенге, склады, характеристики, оригинальная карточка и сертификат, если ссылка предоставлена источником.
- AI-консультация с контекстом сессии, RU/KK, источниками и фотографиями.
- PDF, DOCX, XLSX, CSV, TXT, JPEG, PNG, WEBP: до 3 файлов суммарно 3 МБ. Старые DOC/XLS нужно сохранить как DOCX/XLSX. Для PDF-сканов без текста используйте изображение страницы.
- Сравнение и объяснимые кандидаты на замену по критическим электрическим характеристикам. Противоречия источника отмечаются явно.
- Оплата и доставка по официальной странице EKT со ссылкой.
- Корзина: предложение → явное подтверждение → повторная проверка наличия и цены → сохранение → `/cart`. Изменение количества и удаление тоже требуют подтверждения.
- Разбор спецификации по строкам: до 12 позиций, ручной выбор кандидатов и количества, групповое подтверждение. Неизвестные артикулы остаются явно ненайденными.
- Сравнение карточек в таблице с фильтром отличий; TXT-выгрузка корзины для менеджера.

### Браузерные проверки

На уже запущенном сервере с настроенными API:

```bash
npx playwright install chromium
npm run test:browser
```

`TEST_BASE_URL` меняет адрес сервера (по умолчанию localhost:3000). `PLAYWRIGHT_CHANNEL=chrome` позволяет использовать установленный Chrome. Тесты работают в отдельных сессиях, не меняют пользовательскую корзину. Скриншоты сохраняются в игнорируемый `test-results/`. HTTP-проверки: `node tests/integration.mjs --chat`.

## Архитектура

```text
React UI (RU/KK)
 ├─ /api/products → индекс → серверный адаптер EKT → карточки + время проверки
 ├─ /api/upload → проверки формата/размера → текст или изображение
 ├─ /api/chat → AI-план → поиск/проверка каталога → ответ с источниками
 └─ /api/cart/propose → подписанное предложение, без изменения корзины
      └─ /api/cart/confirm → согласие + остаток + цена → подписанный cookie
```

AI не имеет инструментов изменения корзины или оформления заказа. Документы и сообщения — недоверенные данные, не системные инструкции. Идентификаторы товаров и предложения контролирует сервер.

Корзина содержит только ID, количество и ревизию в подписанном `HttpOnly`, `SameSite` cookie (`Secure` в production). Предложение связано с сессией, ревизией и текущим nonce; срок — 10 минут. Подтверждение повторно проверяет цену, остаток и `KRATNOST_MIN`. Корзина переживает обновление страницы и перезапуск сервера. `/cart` открывает актуальную корзину текущего браузера, но не переносит её в другой браузер.

## Данные и границы интеграции

Источники: партнёрские `GET /api/products?page=N`, `GET /api/products/detail?id=ID`. `data/catalog-snapshot.json` — реальные подробные карточки с временем получения; `data/catalog-index.json` — индекс поиска. Обновление:

```bash
node scripts/catalog-sync.mjs
node scripts/catalog-index.mjs
```

`source` различает `live` и `snapshot`, `fetchedAt` сообщает время проверки. Неизвестная цена остаётся неизвестной; отсутствующий сертификат не заменяется выдуманной ссылкой.

**Корзина принадлежит прототипу Jarvis.** API корзины ekt.kz не предоставлен. Прототип не оформляет заказ, не резервирует склад и не принимает оплату. Оригинальные товарные ссылки ведут на ekt.kz. Для внедрения требуется согласованный адаптер корзины и авторизации действующего магазина.

Известное противоречие источника: ID `515291`, артикул `200300285_` — название/описание указывают 160 А, `NOMINALNYY_TOK` — 250 А. Приложение сообщает об этом и не подтверждает совместимость.

Файлы обрабатываются в памяти, не сохраняются на сервере; текст и изображения передаются OpenAI при AI-запросе. История — в `sessionStorage` вкладки с очисткой. Платёжные данные не запрашиваются.

## Проверка задания

1. Найдите `200300285_`: проверьте цену, наличие, склады, характеристики и предупреждение по API.
2. Спросите о сертификате: при отсутствии ссылки получите честное сообщение, при наличии — ссылку источника.
3. Выберите доступный товар и количество: до подтверждения `/cart` не меняется.
4. Отмените предложение; затем создайте новое и подтвердите — появится товар и ссылка на актуальную корзину.
5. Укажите количество больше остатка или нарушающее кратность: сервер отклоняет действие. Изменение остатков/цены между этапами покрыто тестами.
6. Спросите про оплату/доставку, переключите язык на қазақша, продолжите диалог.
7. Загрузите спецификацию или фото: выполните поиск. Само содержимое файла ничего не добавляет в корзину.
8. Сравните товары, запросите аналог: проверьте совпадение критических параметров и объяснение.

## Публикация и ход разработки

Vercel: стандартный Next.js runtime с серверными переменными Production. Развёртывание выполняется напрямую из локальной папки командой `npx vercel deploy --prod --yes`; GitHub-интеграция для деплоя не требуется. Репозиторий организатора остаётся основным репозиторием разработки. Ход работы: [docs/PROGRESS.md](docs/PROGRESS.md).

## Использованные материалы

Основная функциональность разрабатывается во время хакатона с помощью OpenAI Codex и параллельных AI-агентов. Заранее подготовленные пользователем отдельные HTML/CSS/JS-заготовки использованы как визуальная основа: фон точек, объёмный логотип, навигация, кнопка, поле ввода, эффекты прокрутки.

Стек: Next.js/React, TypeScript, OpenAI SDK, Zod, Lucide, Mammoth, ExcelJS, pdf-parse. Лицензии зависимостей находятся в npm-пакетах; версии зафиксированы в package-lock.json. Шрифт PP Neue Machina предоставлен пользователем; уведомление сохранено в `public/fonts/COPYRIGHT.txt`. Товарные данные и изображения предоставлены EKT.

Вход/выход AI ограничены по размеру, вложениям и частоте запросов на процесс. Общий финансовый лимит задаётся на стороне провайдера: локальный rate limit не является глобальным лимитом расходов.
